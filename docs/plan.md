# Plán MVP

| Krok | Obsah |
|---|---|
| 1 | Dátový model a plán (tento dokument, `datovy-model.md`) |
| 2 | Kostra aplikácie: Tauri 2, React, TypeScript, Vite, Mantine, SQLite cez `tauri-plugin-sql`, migrácie, build pre Windows v GitHub Actions |
| 3 | Dátová vrstva: Drizzle schéma, repozitáre, testy na SQLite |
| 4 | Zákazníci a kontaktné osoby |
| 5 | Faktúry: zoznam, filtre podľa stavu, ručné zadanie, ručná úhrada, upozornenia na splatnosť, Prehľad |
| 6 | Import exportu z iDokladu (.xlsx/.csv) s mapovaním stĺpcov a náhľadom |
| 7 | Ponuky s položkami, pipeline (nástenka), zákazky |
| 8 | PDF cenovej ponuky, nastavenia firmy a loga, fáz, číslovania, zálohy |

Mimo MVP: API iDokladu (len pri vyššom pláne), synchronizácia medzi
zariadeniami (Turso), viac používateľov, napojenie na banku.
